# Entrega da atividade

Esta pasta reúne os arquivos necessários para entregar a atividade prática:

- `RELATORIO-ATIVIDADE.md`: relatório com configuração, resultados, respostas e conclusão;
- `plano-inicial.jmx`: plano de testes do Apache JMeter;
- `planilha-resultados.csv`: resultados da rota principal `GET /api/chamados`;
- `desafio-extra.csv`: resultados do desafio com `GET /api/relatorio`;
- `cenarios.js`: script auxiliar para repetir os cenários pelo terminal.

Antes de entregar, preencha os nomes dos integrantes no relatório e acrescente as capturas de tela solicitadas.
